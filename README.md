# Attendance-Tracker-Python
A beginner-friendly Python mini project that manages class attendance using core data structures: a dictionary maps each student to a list of attendance marks (P for present, A for absent).
Features
1.Add students and mark daily attendance
2.Update or correct a past attendance entry
3.Display all records in a formatted table
4.Calculate each student’s attendance percentage
5.Flag students below a chosen attendance threshold (e.g. 75%)
6.Input validation for unknown students, invalid statuses and out-of-range days
